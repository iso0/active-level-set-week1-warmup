## Deliberately unresolved before arrival

The frozen core intentionally leaves the future batch's grouping, split construction, repeat count, seed list and technical exclusions to a pre-label owner decision. The implementation exposes only the options it can execute and verify: canonical units, `group_token`, an explicit five-fold group assignment, at least two repeats, the Phase 1.21 paired percentile bootstrap, fixed stop/fallback rules and distinct output paths. The addendum records every manifest row as included or technically excluded.

The desired horizon remains B16-B80. Neither intake nor execution shortens it. A batch or generated training fold that cannot reach B80 stops. The runner also stops if the feature-only B16 prefix lacks both observed classes or if q20 contains no examples from one class.
