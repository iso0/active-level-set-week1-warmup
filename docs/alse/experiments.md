# Experiments index

One row per archived experiment (Table A), one row per lean experiment script (Table B), then the naming map that ties legacy identifiers to the corrected chronology.
Archive paths are relative to the archive root `../thesis_work_chatgpt` (override with `ALSE_ARCHIVE`). Lean names are those of `docs/architecture.md`.
Status vocabulary: canonical (a result or definition the thesis relies on), superseded (replaced by a later phase), diagnostic (a closed side question), dead (no downstream use), infrastructure (shared code without a result of its own).
"q20 AULC" is the trapezoid area of the learning curve over budgets 16-80 divided by 64, on the 20% of test rows nearest the empirical boundary. Phase 6/7 report q20 error AULC (lower is better); Week 8.5 and Week 9 report B1-q20 accuracy AULC (higher is better). Bracketed pairs are 95% intervals.
Every number is copied from the artifact named in its row. Where the Week 8 consolidation wording conflicts with the frozen Week 8.5 ledger or the H=320 closure, the later frozen result wins and the row says so.
Rule from `CLAUDE.md`: when a lean experiment concludes, add one row to Table B and one dated entry to `docs/decisions.md`.
