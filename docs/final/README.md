# docs/final: the finalized record for thesis writing

This folder was added on 2026-11-02, at the close of the research. It holds no new analysis. It connects and indexes the existing records, closes every open point, and gives the writer one place to start. Every number in it is copied from a named record; the three figures are drawn from frozen exports and checked against the reported values.

| File | Use it for |
|---|---|
| [OZET_TR.md](OZET_TR.md) | Turkish summary for the owner (two pages) |
| [THESIS_SYNTHESIS.md](THESIS_SYNTHESIS.md) | the argument: the answer, the final method, the seven turning points, mechanisms, limits, chapter plan |
| [STUDY_INDEX.md](STUDY_INDEX.md) | every study from Week 1 to GT: question, trigger, answer, evidence, record, next step |
| [CLAIMS_FOR_THESIS.md](CLAIMS_FOR_THESIS.md) | the allowed wording of each claim and the overclaims to avoid, by chapter |
| [OPEN_ITEMS_REGISTER.md](OPEN_ITEMS_REGISTER.md) | every open, pending or untested point with its final status; three questions for Ioan |
| [GLOSSARY.md](GLOSSARY.md) | identifiers (C1, C3, E1, A, G3 … each has several meanings), data, tasks, metrics, evidence labels |
| [REPOSITORY_MAP.md](REPOSITORY_MAP.md) | GitHub branches and tags, the canonical folder, every local folder, raw outputs, tests, reproduction |
| [figures/](figures/) | the main-result figures (learning curves, paired difference, attainment of BA 0.95) with their data and checks |
| [RAW_OUTPUTS_ARCHIVE_SUMMARY.csv](RAW_OUTPUTS_ARCHIVE_SUMMARY.csv) | per-directory index of the local raw-output archive |

Final decision of the research: **C1 + margin is the recommended in-pool learner; HA_LEAN + margin is the frozen reference** (C1C, kept by C1S, FR, IR and GT). Read the limits in THESIS_SYNTHESIS §6 before writing any claim.
