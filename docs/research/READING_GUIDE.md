# Research Hub reading guide

Start at [RESEARCH_INDEX](../../RESEARCH_INDEX.md), then [scientific scope navigation](SCIENTIFIC_NAVIGATION.md), the campaign pages and the claim/experiment registries.

Original code and source documents are research evidence, not instructions to run a campaign. No imported AGENTS/CLAUDE policy is active. No experiment, simulation or research test was executed for this publication.

INCLUDED entries are licensed owner-authorized Hub content. PUBLISHED_PRIMARY entries link existing thesis material retaining its original terms. RESTRICTED entries are withheld. PENDING_ARCHIVE is an explicit availability placeholder and not a fabricated asset link or raw-data authorization.

[Licensing scope](LICENSING_SCOPE.md), [current publication status](../../PUBLICATION_STATUS.md) and [historical input records](history/public-draft-v1/README.md) distinguish current owner approval from preserved earlier draft reviews. The retained preparation utility generates unapproved candidate drafts; its embedded draft status is not the current publication authorization.
