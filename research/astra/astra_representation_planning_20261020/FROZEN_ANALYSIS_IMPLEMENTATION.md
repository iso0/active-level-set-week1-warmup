# Finishing implementation, before endpoint interpretation

The scientific protocol was frozen before TEST. This document records its
finishing implementation while the detached TEST queue runs; no TEST efficacy
table was used to select the model, selector, target, seeds, tolerances or
success condition. Only operating states/counts and resource waits were inspected.

The finishing observer waits until all TEST units are terminal. It then runs,
one owned numerical thread at a time: adapter/accounting fixtures; the registered 352 feature-only search
paths; cached-result analysis; full paid-path/snapshot integrity; the 24
prespecified numerical replays; prespecified scientific figures; and local bundle
assembly. Stage hashes and output identities are pinned in FROZEN_FINISHING_V1.json.
Completed stage artifacts are reused by hash. Failed stages remain in history
and independent later stages can proceed. A resource wait is retryable, not
evidence that the scientific method failed.

The primary bootstrap retains all arms of a world together. It draws whole-world
multinomial counts within each fixed family, reuses those counts across metrics
and contrasts, and re-estimates conditional-hit denominators. This is equivalent
to drawing world IDs with replacement. The deterministic seed combines the
registered analysis seed with a SHA256-derived ID-list namespace; it contains
no outcomes. Six joint intervals use the maximum standardized deviation.
Secondary and compute-budget intervals are pointwise descriptive.

Undefined classes/bands and empty evaluator islands retain explicit denominators.
The conditional-island primary requires both a valid common-prefix hit and a
nonempty evaluator island. A missing required family disables a clean primary
gate. Missing scientific paths also disable it; missing-outcome bounds use
the [0,1] endpoint range and preserve unknown conditional eligibility.

Equal-compute tables use the last observed readout within the registered cap.
Paired comparisons require BOTH predictions to be available for that world.
Availability-conditional curves are labelled and cannot substitute for these
paired tables. No endpoint past B48 is invented.

Numerical replay refines the 24 frozen snapshots, not the scientific algorithms.
GH65/129 working-Gaussian and GH129/257 mixture comparisons measure bounded
integration differences. They are not independent exact posterior references;
the independent dense/root-partitioned toy checks remain the separate reference.
No TEST tie triggers higher settings or a changed query.

The seven preselected geometric figures reconstruct saved B32/B48 predictions
on x2=x3=0.5. Reconstruction fits are charged to the finite reference ledger;
identical paid sets/model types are reused. Learned-ARD B48 parameters come from
its saved checkpoint; B32 reconstructs its original deterministic paid-only
initial fit. Metrics must match the saved run within 1e-8. The figures show
projected 4D paid points, explicitly not measurements all lying in the slice.

Reported trajectory CPU starts after synthetic-world generation. It includes
fit, decisions, evaluator and checkpoint/file work, but excludes interpreter
startup/world generation/supervisor time. Attempt timestamps provide an
additional wall-time ledger. Pre-checkpoint interruptions can under-record
actual CPU; their reservations and attempts remain. No physical simulator
duration was measured and no physical-hour saving is inferred.

The finishing observer ends at **human review required**, not campaign complete.
Every scientific figure and the mechanism/strong-control results must still
be inspected before the final thesis-ready report. The absolute clock and all
owner/resource restrictions are unchanged.
