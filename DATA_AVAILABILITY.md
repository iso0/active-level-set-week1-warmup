# Data and execution-evidence availability

Research Hub v1 publishes reviewed original text, code and reading-layer metadata. It adds no simulation dataset, raw compressed unit record, NPZ checkpoint, SQLite database, figure, PDF or protected evaluation target.

[ARCHIVE_MANIFEST](docs/research/ARCHIVE_MANIFEST.md) marks unpublished execution evidence PENDING_ARCHIVE. This status does not claim that a GitHub Release asset exists, that data can be downloaded, or that redistribution permission has been granted. RESTRICTED entries remain excluded. No Release URL was invented and no Release was created.

Reported values are retained from the source reports and existing claim ledger; they were not recomputed. Synthetic latent-monitor results, historical Track A controls, OLD depth-threshold findings, binary-label endpoints and later C1C in-pool decisions keep their distinct scopes. None establishes new external physical validation.

Additional evidence packages need separate inventory/rights decisions, content checksums and authorized Release boundaries. Existing physical preservation backups and private forensic manifests were not changed. The sealed oracle remains excluded and was not accessed.
