# Tarihsel R&D kodları

Bu klasör, önceki `reports/` ve `Claude outputs/` içindeki Python dosyalarını içerir.
Tekrarlanan iç içe klasör adları kaldırıldı; orijinal içerikler kaynak manifestinde kayıtlıdır.
Bu yardımcı araştırma kodlarının bir kısmı `/home/claude/` gibi eski ortam yolları kullanır
ve dosya içe aktarımında uzun deneyler başlatabilir. Birleştirme sırasında bu deneyler
yeniden çalıştırılmadı veya bilimsel olarak doğrulanmış ana uygulamalarla değiştirilmedi.
Girdi/çıktı karşılıkları `outputs/research/` altında, kesin eski-yeni yollar kaynak
manifestindedir. Ana haftalık uygulamalar `src/week*.py` dosyalarındadır.
