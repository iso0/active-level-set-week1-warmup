# POST-HOC EXPLORATORY — NOT PRE-REGISTERED CONFIRMATORY EVIDENCE

This is a mechanical mechanism diagnostic of the 100 initial designs fixed before label access. It is not a rerun, repair, alternative design, or confirmatory result.

All 100/100 training pools contain both classes. The frozen feature-only B16 contains one class in 3/100 splits and both classes in 97/100 splits.

For each fixed pool, the descriptive uniform-without-replacement reference is `(C(n0,16)+C(n1,16))/C(N,16)`. Summing those 100 probabilities gives 20.805190. The fixed pools are not treated as independent trials, and no p-value is computed.

The accompanying files contain per-split class counts, per-repeat failure counts, minority-count distributions, and included-only class-conditioned min/median/max input summaries. No significance test, cutpoint search, new seed, acquisition arm, model fit, prediction, endpoint, oracle read, or withheld-outcome access was performed. Interpretation and any future design decision remain separate.
